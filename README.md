# Envato Elements Footage Picker

Userscript для Tampermonkey: визуальная подборка футажей Envato Elements, папки, HTML-экспорт и загрузка через веб-интерфейс Filesta.

Интерфейс автоматически выбирает язык при загрузке страницы: русский для основного языка браузера `ru` (включая `ru-RU`), английский для остальных. Подсказки, сообщения и HTML-экспорт используют выбранный язык. После смены языка браузера перезагрузите Envato. Названия футажей и папок сохраняются в исходном виде.

## Установка и обновления

[Установить актуальный скрипт](https://raw.githubusercontent.com/S-motion/envato-picker/main/Envato-Elements-Footage-Picker.user.js)

Откройте ссылку в браузере с Tampermonkey и подтвердите установку или обновление существующего Envato Elements Footage Picker. Затем перезагрузите страницу Envato. Не устанавливайте вторую копию: сохраните имя и namespace существующего скрипта, чтобы осталась его подборка.

В заголовке настроены `@updateURL` и `@downloadURL`. Tampermonkey проверяет новые версии по своим настройкам обновления. Проверку также можно запустить командой проверки обновлений в меню Tampermonkey. Мгновенное обновление после каждой правки не гарантируется.

Если скрипт раньше был вставлен вручную, один раз обновите его по ссылке выше. Если индивидуальные настройки старой установки переопределяют адрес обновления, выберите в настройках скрипта адреса из заголовка. После этого ручное копирование кода не требуется.

## Возможности

- Выбор карточек, папки и групповые действия.
- Миниатюры с видео по наведению, адаптивная сетка и полноэкранный просмотр.
- Компактные иконки с локализованными подсказками; служебные действия в меню ⋯.
- Автоскрытие окна через 4 секунды после ухода мыши. При вводе и работе клавиатурой окно остаётся открытым.
- Экспорт HTML; резервная копия и импорт JSON; отмена удаления.
- Одиночное и групповое скачивание через веб-форму Filesta в фоновой вкладке.
- Кнопки подбора и Filesta на странице материала доступны как гостям, так и авторизованным пользователям с кнопкой Add to Workspace.

Для Filesta нужна активная сессия в том же профиле браузера. При запросе входа или проверки откройте служебную вкладку. Скрипт не обходит проверки сервиса и не отправляет незавершённые запросы повторно автоматически. Подписанные ссылки скачивания не сохраняются.

Подборка и её превью хранятся локально в Tampermonkey. Репозиторий содержит код; персональные подборки, cookies и учётные данные сюда не отправляются.

## Разработка

Редактируйте `Envato-Elements-Footage-Picker.user.js`, увеличивайте `@version` при публикации и обновляйте ветку `main`. Имена и ключи сохранённых данных должны оставаться совместимыми.

```sh
node --check Envato-Elements-Footage-Picker.user.js
node --test tests/collections.test.cjs tests/filesta-web.test.cjs
```

Используйте отдельное хранилище при браузерной отладке, чтобы не изменять реальную подборку.
